CONTADOR DE CALORÍAS — V1

Esta es la primera versión del código base.

Incluye:
- Calculador automático con fórmula Mifflin-St Jeor.
- Cálculo de metabolismo basal (BMR).
- Cálculo de mantenimiento (TDEE) según actividad.
- Objetivo para bajar, mantener o ganar peso.
- Déficit configurable de 10%, 15% o 20% para bajar de peso.
- Registro diario de alimentos.
- Cálculo automático de calorías según gramos.
- Lista inicial de alimentos comunes.
- Creación de alimentos personalizados.
- Creación de recetas y cálculo de calorías por porción.
- Guardado local de datos en el navegador/dispositivo.
- Diseño adaptado para teléfono.

IMPORTANTE:
Los valores iniciales de alimentos son aproximados. El usuario puede crear alimentos personalizados usando la información de una etiqueta nutrimental.

ESTRUCTURA:
index.html   Interfaz principal
styles.css   Diseño
app.js       Cálculos y funcionamiento
manifest.json Configuración básica tipo PWA

SIGUIENTE ETAPA SUGERIDA:
1. Mejorar el registro de alimentos para permitir piezas, tazas y otras unidades.
2. Agregar edición/eliminación de alimentos personalizados.
3. Permitir registrar una receta por gramos consumidos, además de por porción.
4. Agregar historial diario y seguimiento de peso.
5. Empaquetar esta versión como APK Android.
